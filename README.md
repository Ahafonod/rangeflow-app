# RangeFlow — Poker Preflop Range Viewer, GTO Chart Builder & SRS Trainer

**[Launch RangeFlow in Your Browser →](https://www.rangeflow.top/)**

RangeFlow is a web application designed to build, visualize, and drill Texas Hold'em preflop poker ranges directly in your browser.

## Key Features
- **Interactive 13x13 Range Matrices:** Build, customize, and color-code preflop poker charts with clean visual weights.
- **Dynamic 2–9 Player Table Views:** Visualize positional ranges across heads-up, 6-max, and full-ring table layouts.
- **4-Box Leitner Spaced Repetition (SRS) Trainer:** Drill your ranges and automatically isolate preflop leaks until they are mastered.
- **Auto-Pure & Advanced Training Modes:** Streamline chart creation and daily hand practice sessions.
